# AI Quest: Learn AI in an Hour

A fun, interactive, and gamified web application that teaches beginners the core concepts of Artificial Intelligence through engaging lessons and mini-games.

## Features

- **6 Interactive Modules** covering essential AI concepts
- **Gamification System** with points, levels, and badges
- **Interactive Quizzes** and hands-on activities
- **Beautiful, Friendly UI** designed for engagement
- **Mobile Responsive** - works on all devices
- **No Dependencies** - pure HTML, CSS, and JavaScript

## What You'll Learn

1. **What is AI?** - Introduction to Artificial Intelligence
2. **Machine Learning Magic** - How machines learn from data
3. **Neural Networks Unveiled** - Understanding neural networks
4. **Training Your AI** - The AI training process
5. **AI in Action** - Real-world applications
6. **AI Ethics & Future** - Responsible AI and future implications

## How to Use

Simply open `index.html` in any modern web browser. No installation or setup required!

```bash
# Open directly in browser
open index.html

# Or with a local server
python -m http.server 8000
```

Then navigate to `http://localhost:8000` in your browser.
